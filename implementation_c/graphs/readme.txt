# Graph Data Structures

This directory contains two different ways to represent graphs:

## `adjacency_list/`

An adjacency list representation of a graph.

- `graph_adj_list.c` - adjacency list implementation
- `graph_adj_list.h` - header file for the adjacency list graph code
- `main.c` - example or test driver
- `adj_list.png` - diagram showing the adjacency list structure
- `Makefile` - build instructions for this example

## Traversal note
- DFS would use the stack implementation
- BFS would use the queue implementation

RUNNING THE PROGRAMME:
    To run the file the entire programme, make sure you are in the /adjacency_list directory and then 
    run the command - "make vis" , this would automatically build the necessary object files and run
    the project automatically. Please note that the entire project would be compiled with gcc, if you are
    on a mac and would love to run this same programme, navigate to into the /adjacency_list and open up 
    the Makedfile and make modifications accordingly.
